# Exploratory threshold covariances

These eight exact finite-chain calculations found no positive covariance
between equal threshold indicators at the tested separations. This is not
a proof of negative association, any uniform covariance estimate, or the
thermodynamic limit. The main capped-transfer proof does not use them.

Run `python3 covariance_probe.py` from this directory or pass its full path.
The script uses only the standard library and the shared exact solver.
