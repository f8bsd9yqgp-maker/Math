# The shortest binary superstring containing every Lyndon word of length eleven

**Theorem (finite, independently reproducible certificate; 12 October 2026).** The shortest binary string containing all binary Lyndon words of length eleven as contiguous factors has length **715**.

*Research status:* This is an AI-assisted proof and finite certificate, not an independently refereed paper. The length-eleven instance is a natural extension of TheoremDB's length-eight problem; this report does not assert that length eleven was previously recorded as open, nor that the result is unpublished elsewhere.

## 1. Graph model

A binary Lyndon word is lexicographically smaller than each of its nontrivial cyclic rotations. There are exactly `(2^11 - 2)/11 = 186` binary Lyndon words of length 11. We use the binary order-ten de Bruijn digraph: vertices are 10-bit strings, identified with integers `0,...,1023`, and the two directed edges from vertex `u` lead to `(2u) mod 1024` and `(2u+1) mod 1024`. Every 11-bit word is exactly one of its 2048 directed edges, beginning at its 10-bit prefix and ending at its 10-bit suffix.

Thus a binary string `S` of length `L >= 11` spells a walk with `L-10` directed edges. Covering the 186 required words means the walk traverses every corresponding required edge at least once.

## 2. An explicit potential certificate

For vertices `a,b`, define `d(a,b)` to be the length of a shortest directed path from `a` to `b` in this de Bruijn graph. It has the direct formula

`d(a,b) = min { k in {0,...,10} : suffix_(10-k)(a) = prefix_(10-k)(b) }`.

Take the following **60 zero-weight anchors**:

```
203 217 233 243 249 295 299 301 303 307 309 311
315 317 319 331 333 335 339 359 371 373 411 413
415 423 427 429 431 437 445 463 469 471 475 477
491 493 501 503 507 509 683 687 695 699 703 727
731 735 751 759 763 767 879 887 895 959 991 1023
```

And the following **11 further `(vertex, weight)` anchors**:

```
(67,6), (113,4), (137,7), (139,7), (141,7),
(143,7), (163,5), (199,6), (201,3), (229,2), (293,2)
```

Let `A` be the list of all 71 anchors with weights `c(a)` as above, and define for **every** vertex `v`:

`p(v) = min(10, min_{a in A} (c(a) + d(a,v)))`.

Since shortest-path distance obeys `d(a,v) <= d(a,u)+1` across each directed edge `u -> v`, we have

**Potential lemma:** `0 <= p(v) <= 10` and `p(v)-p(u) <= 1` on **every one** of the 2048 directed edges.

This is a mathematical consequence of the given explicit formula, not an unverified assumption about the output of an optimizer.

## 3. Required-edge decrease equals 529

For each vertex let `Delta(v)` be the number of *required* outgoing edges minus the number of *required* incoming edges. Direct enumeration of the Lyndon words yields 71 vertices with `Delta=+1`, 71 with `Delta=-1`, and 882 with `Delta=0`.

The following table shows the counts of potential values on the imbalanced vertices, each independently regenerated by `lyndon11_verify.py` from the 71 explicit anchors above.

| Potential `p` | Number with `Delta=+1` | Number with `Delta=-1` |
| ---: | ---: | ---: |
| 0 | 0 | 60 |
| 2 | 10 | 2 |
| 3 | 3 | 1 |
| 4 | 2 | 1 |
| 5 | 0 | 1 |
| 6 | 0 | 2 |
| 7 | 4 | 4 |
| 10 | 52 | 0 |

Because every required edge contributes `p(tail)-p(head)` to the potential decrease, their **total** contribution, no matter where in a containing string they occur, is

```
D = sum_{required edge u->v} [p(u)-p(v)]
  = sum_{vertices v} Delta(v)*p(v)
  = (52*10 + 4*7 + 2*4 + 3*3 + 10*2)
    - (4*7 + 2*6 + 1*5 + 1*4 + 1*3 + 2*2)
  = 585 - 56
  = 529.
```

## 4. Universal lower bound

Consider **any** string of length `L` covering all 186 required words, and select one occurrence of each of the 186 distinct required factors. Those 186 graph edges decrease the potential by 529 in total. There are `(L-10)-186=L-196` other edges; each can increase the potential by at most one by the potential lemma. Consequently,

`p(last)-p(first) <= -529 + (L-196) = L-725`.

Because the potential lies in `[0,10]`, the change on the left is at least `-10`. Hence

`-10 <= L-725`, so **`L >= 715`**.

This bound applies to **every** possible common superstring, not just a class with a chosen block ordering.

## 5. Matching 715-bit construction

The file [`lyndon11_witness.txt`](lyndon11_witness.txt) gives an explicit binary string of length **715**. Direct substring testing confirms it contains all 186 length-eleven binary Lyndon words. Its SHA-256 checksum, treating the 715 ASCII `0`/`1` bytes **without a newline** as the hashed input, is:

```
50ffb7e470791f2acc4b4a2227f74d7f193f73ba6696e2e67461c6cb10edc60f
```

In fact, the witness starts at potential 10 and ends at potential 0. The 519 non-required edge occurrences *each* increase the potential by exactly one, while the 186 selected required occurrences decrease it by exactly 529. Thus **both inequalities in the lower-bound proof are attained with equality**.

Since `L >= 715` universally and this witness has `L=715`, the exact optimum is

**`L_11 = 715`. QED.**

## 6. Independent replication

Run `python3 lyndon11_verify.py` alongside `lyndon11_witness.txt` in the same folder. This verifier uses **only the Python standard library**, generating all 186 target words from the Lyndon definition, deriving the potential using both the overlap-distance formula and an independent multi-source shortest-path computation, verifying all 2048 potential inequalities, recomputing the drop of 529 in two ways, and checking the witness and its tightness edge by edge.

The exploratory search used linear optimization to find a favorable potential and minimum-cost flow to find a matching construction. **Neither solver is needed for the independent certificate.** Reproduction needs only the two attached text files and ordinary Python.
